# HKSI Paper 7：从零理解金融市场

这套资料写给没有金融背景、希望把概念真正想明白的学习者。你只需要会日常加减乘除；百分比、复利、公式里的字母都会从头解释。默认每天学习约 60 分钟，按 12 周逐步完成。

**第一步：打开[第一课：钱为什么需要金融](01-foundation/01-money.md)。** 今天先读完一个小节，画出一次借钱交易中的资金流，再用自己的话复述。暂时不必背所有机构缩写，也不用一次看完这里的全部资料。

## 怎样使用这套资料

每篇正文分为三种深度：**先理解**帮助建立直觉，**考纲学习**整理正式机制与计算，**扩展理解**说明边界或进一步联系。看到新词，先看本节解释，再查[术语表](04-reference/02-glossary.md)。计算卡住时，回到[基础数学](01-foundation/04-math.md)。

推荐学习顺序是“预备课 → 七章正文 → 章节练习 → 错题补学 → 综合练习”。每章三篇正文可以分多天读；“读完”与“会解释、会应用”分开记录。答案放在独立文件，做题时先关闭答案页面。

学习路线、每日任务和复习日期见[12 周路线](05-study/01-12-week-plan.md)。本资料的学习节奏和题量分配是教学安排，不代表官方考试章节权重。
