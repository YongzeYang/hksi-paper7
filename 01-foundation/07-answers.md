# 预备课自测解析

[返回目录](../README.md) · [第一课](01-money.md) · [掌握检查](../05-study/03-mastery.md)

先完成各课问题，再对照下面的推理。没有选择题选项时，也要说出容易走错的那一步。

| 题号 | 答案与关键理由 | 补学 |
|---|---|---|
| P01 | 借款增加现金，也增加还款义务；融资不等于销售收入。 | [钱与金融](01-money.md) |
| P02 | 通常付给卖出该股票的原持有人，二级市场交易本身不会把同一笔买入款再交给发行公司。 | [钱与金融](01-money.md) |
| P03 | 不等于。净资产的简化值是 200,000，房屋也不等于随时可用现金，还要考虑出售与偿债。 | [钱与金融](01-money.md) |
| P04 | 利润 50,000−35,000=15,000；现金净额 30,000−35,000=−5,000，差异来自未收款。 | [公司与现金流](02-company.md) |
| P05 | 不能。获得现金伴随负债增加，不能作为销售盈利。 | [公司与现金流](02-company.md) |
| P06 | 付款是购置时现金流出；折旧是将资产成本分配到使用期间。若无残值且两年直线折旧，每年费用6,000，不是每年重新付6,000。 | [公司与现金流](02-company.md) |
| P07 | 权益=500,000−180,000=320,000。不能再把负债加上去。 | [资产负债](03-balance-sheet.md) |
| P08 | 现金资产减少30,000，贷款负债减少30,000，权益不因单纯归还本金而改变；利息另算。 | [资产负债](03-balance-sheet.md) |
| P09 | 对客户是向银行收款的资产；对银行是向客户付款的负债。先指定观察主体。 | [资产负债](03-balance-sheet.md) |
| P10 | 不一定。借款支持资产时，资产的损失由较少的权益先承担，权益百分比损失可能更大。 | [杠杆例子](03-balance-sheet.md) |
| P11 | 上涨 (60−50)/50=20%；下跌 (50−60)/60=−16.67%，基数不同。 | [基础数学](04-math.md) |
| P12 | 增加0.5个百分点=50bp；相对原利率的增幅为20%，是另一个问题。 | [基础数学](04-math.md) |
| P13 | 6,000×0.04×3/12=60元，不能将3个月当3年。 | [基础数学](04-math.md) |
| P14 | 0.6×10%+0.4×(−5%)=4%；不是把10%与−5%直接平均。 | [基础数学](04-math.md) |
| P15 | 单利1,000×(1+0.1×2)=1,200；复利1,000×1.1²=1,210，差10来自第一年利息的利息。 | [时间价值](05-time-value.md) |
| P16 | 1,050/1.05=1,000。不能直接减去1,050的5%，因为5%的起点是现值。 | [时间价值](05-time-value.md) |
| P17 | 降低。在固定未来付款下，较高要求回报需要较低的今天买入价。 | [时间价值](05-time-value.md) |
| P18 | (45−50+2)/50=−6%，收到股息仍不足弥补价格损失。 | [风险回报](06-risk-return.md) |
| P19 | 否。预期是模型的概率加权平均，不是每次结果或保证；概率估计也可能出错。 | [风险回报](06-risk-return.md) |
| P20 | 不能。共同经济因素仍会影响组合，同业持仓还可能高度相关。 | [风险回报](06-risk-return.md) |

复述任务不要求固定措辞，但要包含主体、现金流、时间、权利义务与一个反例。若只会背“风险越高收益越高”，请改为“投资者通常要求更高预期补偿，但实际收益可能很低或亏损”。
