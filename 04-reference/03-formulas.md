# 公式速查：每个公式都带条件

[目录](../README.md) · [先修数学](../01-foundation/04-math.md) · [完整算例](../03-calculations/01-interest.md) · [下一份](04-institutions.md)

金额单位、利率小数、时间单位先统一。PV现值，FV终值，P价格/本金依语境，F面值，C每期票息，y每期收益率，n期数；公式同字母在不同题中可能另有定义。

| 用途 | 公式 | 必须检查 |
|---|---|---|
| 变动率 | (新−旧)/旧 | 分母为原基数 |
| 单利利息 | I=P×r×t | 年率配年数，日数按题设 |
| 复利终值 | FV=PV(1+r)^n | r每期、n期数，再投资假设 |
| 折现 | PV=FV/(1+r)^n | 每笔不同日期分别算 |
| 名义到有效年率 | EAR=(1+j/m)^m−1 | j是名义年率，m年复利次数 |
| 有效年到每期 | (1+EAR)^(1/m)−1 | 不能总用EAR/m |
| 实际购买力回报 | (1+名义回报)/(1+通胀)−1 | 相减只是小变动近似 |
| 年化复合回报 | (期末/期初)^(1/年数)−1 | 无中途现金流的简例 |
| 持有期总回报 | (期末价−期初价+分配)/期初价 | 同单位、是否扣费、期限 |
| 市值 | 每股价格×适用股数 | 不等于公司现金或净资产 |
| P/E | 股价/EPS | 盈利口径及亏损边界 |
| P/B | 股价/每股账面净资产 | 会计可比性和资产质量 |
| 固定增长股息模型 | P0=D1/(k−g) | k>g且长期增长假设适用 |
| 供股TERP | (旧股数×旧价+新股数×认购价)/(总股数) | 全认购、忽略其他变化的理论价 |
| 每旧股附权价值 | 旧价−TERP | 先指定权利单位 |
| 零息债价格 | F/(1+y)^n | 每期利率与期数配对 |
| 息票债价格 | Σ[C/(1+y)^t]+F/(1+y)^n | 最后本金只加一次 |
| 票息率 | 年票息/面值 | 不用市场价格作分母 |
| 当期收益率 | 年票息/当前价 | 不计到期资本差价 |
| 全价 | 净价+应计利息 | 日数和报价惯例依合同 |
| 久期近似 | ΔP/P≈−D_mod×Δy | 小变动、修正久期、Δy小数 |
| 回购年化率 | (回购价−融资款)/融资款×1/T | T按指定年数/日数 |
| 汇率倒数 | 1/q | 双边价要倒数并换边 |
| 远期年化升贴水 | (F−S)/S×1/T | 报价方向、日数与年化方法 |
| 简单利率平价 | F=S(1+r_dT)/(1+r_fT) | S为本币/每外币，同日数及约束 |
| 期货价格变动收益 | (终价−初价)×乘数×多头份数 | 空头反向；保证金不同于名义额 |
| 买call利润 | max(S_T−K,0)−c | 每单位；忽略费用和资金时间价值 |
| 买put利润 | max(K−S_T,0)−p | 卖方利润取相反方向 |
| FRA期初结算差额 | N(L−K)T/(1+LT) | 哪方收款、期间起点、利率和日数 |
| 组合回报 | Σw_i r_i | 同期间、无未处理现金流，权重和1 |
| 每单位NAV | (基金资产−负债)/单位数 | 不等于保证成交价 |
| NPV（扩展） | ΣCF_t/(1+k)^t−初始投入 | 现金流与折现率估计可能错 |

别把公式表当作学习顺序。若无法说明“谁付给谁、何时付”，请回[计算专题](../03-calculations/01-interest.md)和相关正文；公式只压缩已经理解的关系。
