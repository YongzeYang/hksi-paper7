# 机构职责速查：先按问题找角色

[目录](../README.md) · [先修：香港章](../02-chapters/02-hk/00-overview.md) · [下一份：产品表](05-products.md)

核验于2026-10-30；这是功能索引，具体适用对象和权限回官方来源核对。

| 缩写/名称 | 中文/繁体 | 主要记忆点 | 官方来源 |
|---|---|---|---|
| HKMA | 香港金融管理局 | 银行、货币稳定与外汇基金等 | [银行职能](https://www.hkma.gov.hk/eng/key-functions/banking/) |
| SFC | 证券及期货事务监察委员会（證監會） | 证券期货及相关中介监管 | [职责](https://www.sfc.hk/EN/about-the-sfc/our-role/) |
| MPFA | 强制性公积金计划管理局（積金局） | 强积金及相关退休计划监管 | [任务](https://www.mpfa.org.hk/en/mpfa/mission-and-role) |
| IA | 保险业监管局（保監局） | 保险业及相应业务监管 | [保险监管](https://www.ia.org.hk/en/supervision/reg_insurers_lloyd/regulation_of_Insurers_and_lloyds.html) |
| AFRC | 会计及财务汇报局（會財局） | 会计专业、审计质量及相关监督 | [职能](https://www.afrc.org.hk/en-hk/about-afrc/our-role) |
| HKEX | 香港交易及结算所有限公司（港交所） | 市场营运与旗下交易结算业务 | [业务](https://www.hkex.com.hk/?sc_lang=en) |
| SEHK / HKFE | 香港联合交易所/香港期货交易所 | 证券/期货交易所角色 | [市场资料](https://www.hkex.com.hk/?sc_lang=en) |
| HKSCC | 香港中央结算有限公司 | 相应证券结算服务 | [证券结算](https://www.hkex.com.hk/Services/Clearing/Securities/Overview/Clearing-Services?sc_lang=en) |
| HKCC / SEOCH | 香港期货结算/联交所期权结算公司 | 各自范围的上市衍生产品结算 | [保障机制](https://www.hkex.com.hk/Services/Clearing/Listed-Derivatives/Risk-Management/The-Safeguards?sc_lang=en) |
| CCASS / DCASS | 中央结算系统/衍生产品结算系统 | 系统名称，不是投资收益担保 | [证券交收](https://www.hkex.com.hk/Services/Settlement-and-Depository/Settlement?sc_lang=en) |
| CMU | 债务工具中央结算系统 | 相关债务证券的存管结算等 | [债务证券基础设施](https://www.hkma.gov.hk/eng/key-functions/international-financial-centre/financial-market-infrastructure/debt-securities-settlement-system/) |
| IMF | 国际货币基金组织 | 国际货币及宏观稳定、国际收支支持 | [IMF](https://www.imf.org/en/About) |
| World Bank | 世界银行 | 发展、减贫及相关项目支持 | [世界银行](https://www.worldbank.org/en/who-we-are) |
| BIS | 国际结算银行 | 央行合作、研究及相应服务 | [BIS](https://www.bis.org/about/index.htm) |

练习记法：普通银行存款问题先想HKMA；证券中介操守先想SFC；退休计划先想MPFA；保险先想IA；审计质量先想AFRC；订单撮合和交收流程再看交易结算机构。跨行业事件可能涉及多个角色。

不要根据英文里出现“bank”“clearing”就推断所有业务和担保范围；同样，“获监管”说明受相应制度约束，不能等同收益保证。
