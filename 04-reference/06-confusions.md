# 易混概念：把错误直觉变成可检查的句子

[目录](../README.md) · [术语](02-glossary.md) · [下一步：掌握检查](../05-study/03-mastery.md)

先遮住右两列，试着纠正左侧说法；会解释反例，比只记“这句错了”更有用。

| 看似合理的错误句 | 反例/纠正 | 回补 |
|---|---|---|
| 有利润就有现金 | 赊销可确认盈利但未收款 | [公司](../01-foundation/02-company.md) |
| 借来钱是收入 | 现金与负债同时增加 | [资产负债](../01-foundation/03-balance-sheet.md) |
| 存款是银行资产 | 对储户是资产，对银行是负债 | [资产负债](../01-foundation/03-balance-sheet.md) |
| 股东拥有公司就能随便取现金 | 公司与个人主体不同，股东持有权益 | [公司](../01-foundation/03-balance-sheet.md) |
| 一级二级看公司大小 | 看新发行还是现有证券转手 | [市场](../02-chapters/01-global/02-mechanisms.md) |
| OTC就是没人监管 | 交易机制不等于监管状态 | [市场](../02-chapters/01-global/02-mechanisms.md) |
| 直接融资不能有投行 | 直接指主要资金请求权关系 | [市场](../02-chapters/01-global/02-mechanisms.md) |
| 资本充足就是现金够 | 损失缓冲与即时付款是两个问题 | [风险](../02-chapters/06-risk/01-core.md) |
| 3%到4%只升1% | 升1个百分点=100bp，相对升33.33% | [数学](../01-foundation/04-math.md) |
| 跌20%后涨20%回本 | 100变80再变96 | [数学](../01-foundation/04-math.md) |
| 名义12%月复利等于一年12% | 有效年率为1.01^12−1≈12.6825% | [利率](../03-calculations/01-interest.md) |
| 红股增加股数就创造财富 | 理论价格同时调整，仍看企业价值 | [供股](../02-chapters/03-equity/02-mechanisms.md) |
| 股价低就是估值便宜 | 还要看盈利、资产、股数及风险 | [估值](../02-chapters/03-equity/02-mechanisms.md) |
| 收到股息/票息就没亏 | 价格损失可能超过收入 | [回报](../01-foundation/06-risk-return.md) |
| 票息率、YTM、实际回报一样 | 分母、现金流和实现条件不同 | [收益率](../02-chapters/04-debt/02-mechanisms.md) |
| 债券利率固定，价格也固定 | 市场要求收益率可变 | [债券](../02-chapters/04-debt/02-mechanisms.md) |
| 久期就是剩余期限 | 现金流加权时间/敏感度须分定义 | [久期](../02-chapters/06-risk/02-mechanisms.md) |
| 汇率数字升就是本币升 | 1USD需更多HKD是港元相对弱 | [外汇](../02-chapters/05-fx-derivatives/01-core.md) |
| 银行买卖价按客户视角写 | 报价者买入bid、卖出ask | [计算](../03-calculations/03-fx-derivatives.md) |
| 远期是可靠预测 | 是合同远期交换价，涉及利率等 | [外汇](../02-chapters/05-fx-derivatives/01-core.md) |
| call是看涨，所以卖call也同方向 | 买卖方支付方向相反 | [四仓位](../03-calculations/03-fx-derivatives.md) |
| 期权价内等于净赚钱 | 支付仍要扣权利金 | [期权](../02-chapters/05-fx-derivatives/02-mechanisms.md) |
| 保证金就是总风险金额 | 小额保证金可对应大名义敞口 | [期货](../02-chapters/05-fx-derivatives/02-mechanisms.md) |
| 对冲保证每一条腿赚钱 | 合并业务与合约看预算和风险 | [对冲](../02-chapters/05-fx-derivatives/03-practice.md) |
| 分散消除全部风险 | 共同市场因素仍存在 | [风险](../02-chapters/06-risk/01-core.md) |
| 99%VaR是最多损失 | 仍有模型中的尾部损失，且估计可能错 | [VaR](../02-chapters/06-risk/02-mechanisms.md) |
| DVP/CCP消灭所有风险 | 解决特定交收和履约机制，不保价格 | [风险](../02-chapters/06-risk/03-practice.md) |
| 客户愿冒险就适合高风险 | 实际损失能力和资金用途也要看 | [顾问](../02-chapters/07-applications/03-practice.md) |
| NAV等于随时可卖价格 | 市场价可折溢价，赎回按条款 | [基金](../02-chapters/07-applications/02-mechanisms.md) |
| 已披露利益冲突就可忽略合适性 | 披露与实质义务不是同一件事 | [顾问](../02-chapters/07-applications/03-practice.md) |

把自己的新错误追加到[错题本](../05-study/02-workbook.md)：我原以为……；实际是……；触发误判的词是……；下次先检查……。
