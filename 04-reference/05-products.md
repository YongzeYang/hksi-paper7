# 金融产品比较：先看现金流与义务

[目录](../README.md) · [先修：回报风险](../01-foundation/06-risk-return.md) · [下一份：易混点](06-confusions.md)

| 工具 | 基本权利/现金流 | 主要风险/限制 | 正文 |
|---|---|---|---|
| 普通股 | 剩余权益，可能股息及出售收入 | 经营、价格、流动性；普通股息不固定 | [股票](../02-chapters/03-equity/01-core.md) |
| 优先股 | 按类别条款取得相应优先权利 | 条款、信用、利率；不自动等于有到期本金 | [股票](../02-chapters/03-equity/03-practice.md) |
| 固定息债 | 约定票息及还本 | 信用、利率、通胀、流动性等 | [债券](../02-chapters/04-debt/01-core.md) |
| 浮息债 | 票息按参考率及条款重设 | 信用、利差、重设和上限等 | [债券](../02-chapters/04-debt/01-core.md) |
| 零息债 | 通常到期一次付款 | 价格对利率可能敏感，仍有信用风险 | [定价](../02-chapters/04-debt/02-mechanisms.md) |
| 可赎回债 | 发行人有适用提前赎回选择 | 上升空间、再投资和条款风险 | [分类](../02-chapters/04-debt/01-core.md) |
| 回购 | 卖证券并约定买回，获得短期现金 | 担保价值、追加抵押、对手方及法律 | [回购](../02-chapters/04-debt/03-practice.md) |
| 外汇远期 | 双方按约定未来交换 | 对手方、义务、机会成本 | [远期](../02-chapters/05-fx-derivatives/01-core.md) |
| 期货 | 双方标准化未来履约 | 杠杆、逐日损益及现金追缴 | [衍生](../02-chapters/05-fx-derivatives/02-mechanisms.md) |
| 买入期权 | 付权利金换选择权 | 可损失全部权利金，到期与条款 | [期权](../02-chapters/05-fx-derivatives/02-mechanisms.md) |
| 卖出期权 | 收权利金，承担相应履约 | 某些裸仓损失可极大甚至无界 | [期权](../02-chapters/05-fx-derivatives/02-mechanisms.md) |
| 利率掉期 | 交换约定利息流 | 参考率、对手方、基差、抵押现金 | [掉期](../02-chapters/05-fx-derivatives/02-mechanisms.md) |
| ETF/基金 | 持有组合的单位权益 | 市场、跟踪、费用、流动性与结构 | [资产管理](../02-chapters/07-applications/02-mechanisms.md) |
| 权证/牛熊证 | 条款决定衍生支付，可能杠杆 | 发行人、到期、强制收回和价格 | [香港产品](../02-chapters/05-fx-derivatives/03-practice.md) |

比较任何两个产品，再填六项：币种、期限、收入是否承诺、退出方式、损失情景、全部费用。一个工具可用于对冲或投机，要看持有人原本敞口及交易目的。名称相同也可能有完全不同的条款。
