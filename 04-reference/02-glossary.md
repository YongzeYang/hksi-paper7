# 中英术语表：先查一句话，再回正文

[目录](../README.md) · [先修：预备课](../01-foundation/01-money.md) · [下一份：公式](03-formulas.md)

香港常见译名列在括号内；同一词在会计、产品合同与宏观语境可能有不同细节，以本节上下文及题干为准。

## 基础与市场

| 中文/香港用词 | 英文/缩写 | 一句话理解 |
|---|---|---|
| 资产（資產） | asset | 主体控制、可带来经济利益的资源 |
| 负债（負債） | liability | 主体承担的现时义务 |
| 权益（權益/股本） | equity | 资产扣负债的剩余利益；语境也可指股权证券 |
| 收入 | revenue | 期间确认的销售等成果，未必已收现金 |
| 费用（費用） | expense | 期间消耗资源确认的成本 |
| 利润（利潤/盈利） | profit/earnings | 收入与费用等相抵后的结果 |
| 现金流（現金流） | cash flow | 一段时间实际现金进出 |
| 应收账款（應收賬款） | accounts receivable | 对客户收款的权利 |
| 折旧（折舊） | depreciation | 将资产成本分配到使用期 |
| 储蓄（儲蓄） | saving | 收入中未消费部分 |
| 融资（融資） | financing | 为支出取得资金 |
| 金融中介 | financial intermediary | 连接资金需求并提供转换等服务的机构 |
| 脱媒（脫媒） | disintermediation | 绕过传统中介渠道取得资金 |
| 一级市场（初級市場） | primary market | 新证券发行的市场 |
| 二级市场（次級市場） | secondary market | 已发行证券转手的市场 |
| 货币市场（貨幣市場） | money market | 通常一年或以内原始期限的融资市场 |
| 资本市场（資本市場） | capital market | 较长期债务与股权融资市场 |
| 场外市场（場外） | OTC, over-the-counter | 在交易所集中市场之外协商交易等 |
| 发行人（發行人） | issuer | 发行证券筹资的一方 |
| 经纪（經紀） | broker | 通常为客户执行交易 |
| 交易商 | dealer | 通常以自有账户买卖 |
| 庄家（市場莊家） | market maker | 按适用安排提供买卖报价 |
| 买入价（買入價） | bid | 报价者愿买入的价 |
| 卖出价（賣出價） | ask/offer | 报价者愿卖出的价 |
| 买卖差价（買賣差價） | bid–ask spread | ask减bid，交易成本的一部分 |
| 清算（結算） | clearing | 计算管理已成交的应收应付与风险 |
| 交收 | settlement | 实际转移资产与资金 |
| 托管（託管） | custody | 按安排保管及管理资产记录等 |

回正文：[预备课](../01-foundation/03-balance-sheet.md)、[全球体系](../02-chapters/01-global/00-overview.md)。

## 经济与香港

| 中文/香港用词 | 英文/缩写 | 一句话理解 |
|---|---|---|
| 本地生产总值（本地生產總值） | GDP | 期间经济体内最终商品服务产出价值 |
| 通胀（通脹） | inflation | 总体价格水平持续上升 |
| 财政政策（財政政策） | fiscal policy | 通过政府支出与税收影响经济 |
| 货币政策（貨幣政策） | monetary policy | 影响货币信贷与金融条件 |
| 审慎监管（審慎監管） | prudential supervision | 关注机构稳健、资本流动性及风险 |
| 联系汇率（聯繫匯率） | LERS | 香港以货币发行局安排联系港元与美元的制度 |
| 货币发行局（貨幣發行局） | currency board | 按规则以外汇支持货币基础等的安排 |
| 兑换保证（兌換保證） | CU, convertibility undertaking | 金管局向银行提供的相应兑换承诺 |
| 总结余（總結餘） | Aggregate Balance | 银行在金管局结算账户余额总和 |
| 外汇基金（外匯基金） | Exchange Fund | 服务法定货币金融稳定目标的基金 |
| 认可机构（認可機構） | AI, authorized institution | 银行监管中的特定机构称谓 |
| 外来直接投资（外來直接投資） | FDI | 涉及持久利益与影响等的跨境投资分类 |
| 证券组合投资（證券投資） | portfolio investment | 跨境证券投资分类，与FDI按正式口径区分 |

机构缩写见[机构表](04-institutions.md)，细节与来源见[香港章](../02-chapters/02-hk/00-overview.md)。

## 股票与债券

| 中文/香港用词 | 英文/缩写 | 一句话理解 |
|---|---|---|
| 普通股 | ordinary/common share | 公司剩余权益及相应股东权利 |
| 优先股（優先股） | preference share | 权利按类别条款规定，不等于普通债券 |
| 股息 | dividend | 向股东分配的款项等，普通股通常不保证 |
| 资本利得（資本增值） | capital gain | 卖价或价值高于成本的增值 |
| 首次公开招股（首次公開招股） | IPO | 首次向公众发行等上市融资安排 |
| 供股 | rights issue | 按适用比例向现有股东提供认购权 |
| 红股（紅股） | bonus issue | 按安排向股东分配新增股份，通常不收认购款 |
| 拆股 | share split | 改变股份单位结构及股数 |
| 理论除权价（理論除權價） | TERP | 按简化条件计算供股后的理论价格 |
| 每股盈利 | EPS | 归属盈利按相应股数口径分摊 |
| 市盈率 | P/E | 股价相对每股盈利的倍数 |
| 市净率（市賬率） | P/B | 股价相对每股账面净资产的倍数 |
| 市值 | market capitalization | 股价乘适用已发行股数 |
| 面值 | par/face value | 债券合同计息及还本等使用的基准金额 |
| 票息（息票） | coupon | 合同每期利息 |
| 收益率（孳息率） | yield | 需看具体定义的收益比率/折现率 |
| 到期收益率（到期孳息率） | YTM | 使约定现金流现值等于价格的折现率 |
| 当期收益率 | current yield | 年票息除当前价格 |
| 收益率曲线（孳息曲線） | yield curve | 可比债券期限与收益率的关系 |
| 信用评级（信貸評級） | credit rating | 对信用质量的意见，不是保证 |
| 信用利差（信貸息差） | credit spread | 相对可比参考债收益率的差异 |
| 回购（回購） | repo | 卖出证券并约定买回，常作担保融资 |
| 折扣 | haircut | 融资与担保品价值间的缓冲比例，需指明分母 |
| 应计利息（應計利息） | accrued interest | 付息期间按规则累计的利息 |
| 净价/全价（淨價/全價） | clean/dirty price | 不含/包含应计利息的相应价格口径 |

回正文：[股票](../02-chapters/03-equity/00-overview.md)、[债务](../02-chapters/04-debt/00-overview.md)。

## 外汇、衍生工具与风险

| 中文/香港用词 | 英文/缩写 | 一句话理解 |
|---|---|---|
| 基础/报价货币（基準/報價貨幣） | base/quote currency | 1单位前者对应多少后者，先看定义 |
| 即期/远期（即期/遠期） | spot/forward | 适用即期交收安排/今天锁定未来交换 |
| 交叉汇率（交叉匯率） | cross rate | 通过中间货币推算的兑换比率 |
| 远期升/贴水（遠期溢/折讓） | forward premium/discount | 远期相对即期的差，方向依报价 |
| 衍生工具 | derivative | 价值由标的或参考变量导出的合同 |
| 期货（期貨） | futures | 标准化交易、相应结算与保证金的合约 |
| 期权（期權） | option | 买方拥有选择权，卖方承担相应义务 |
| 认购/认沽（認購/認沽） | call/put | 按条件选择买入/卖出标的的权利 |
| 行使价 | strike/exercise price | 期权约定买卖价 |
| 权利金（期權金） | premium | 购买期权支付的价格 |
| 到期支付/净利润 | payoff/profit | 合同到期支付/再计入权利金费用等后的结果 |
| 掉期（掉期/互換） | swap | 交换约定现金流的合同 |
| 远期利率协议（遠期利率協議） | FRA | 锁定未来期间利率差等的安排 |
| 对冲（對沖） | hedge | 降低已有风险敞口 |
| 投机（投機） | speculation | 主动承担价格等风险以图收益 |
| 套利（套戥） | arbitrage | 利用相关价格差异，实际仍须看约束 |
| 保证金（按金） | margin | 支持履约的资金/担保，不是全部名义金额 |
| 杠杆（槓桿） | leverage | 用债务或小额资金承担较大经济敞口 |
| 基差 | basis | 本教材为现货−期货，其他资料可反号 |
| 波动率（波幅） | volatility | 价格或回报变化幅度的统计描述 |
| 久期（存續期） | duration | 收款时间加权/利率敏感度等，需分定义 |
| 风险价值（風險值） | VaR | 指定期与置信度的损失阈值 |
| 压力测试（壓力測試） | stress testing | 检查严重情景下损失及可持续运作 |
| 相关性（相關性） | correlation | 共同变化程度，不是概率 |
| 系统性市场风险 | systematic risk | 广泛共同市场因素的风险 |
| 系统连锁风险 | systemic risk | 金融体系相互传染和受扰风险 |
| 货银两讫（貨銀對付） | DVP | 证券转移与付款联动 |
| 付款对付款 | PVP | 两货币付款联动 |

回正文：[外汇衍生](../02-chapters/05-fx-derivatives/00-overview.md)、[风险](../02-chapters/06-risk/00-overview.md)。

## 金融服务

| 中文 | 英文/缩写 | 一句话理解 |
|---|---|---|
| 尽职调查（盡職審查） | due diligence | 获取验证重要信息的过程 |
| 并购（合併與收購） | M&A | 结合企业或收购控制等交易 |
| 净现值（淨現值） | NPV | 未来净现金流现值减初始投入 |
| 资产配置（資產配置） | asset allocation | 在资产类别间分配风险资本 |
| 再平衡 | rebalancing | 按目标/允许范围调整持仓 |
| 净资产值（資產淨值） | NAV | 基金资产扣负债后的净值，按口径可到每单位 |
| 投资政策声明 | IPS | 目标、授权、限制与评估依据 |
| 交易所买卖基金（交易所買賣基金） | ETF | 在交易所交易的基金，风险看结构和底层 |
| 合适性（合適性） | suitability | 产品/服务与客户实际情况相匹配 |
| 认识客户（認識你的客戶） | KYC | 了解核实客户资料；不同规则有特定要求 |
