# 6.3 香港风险管理实务：制度、控制与危机复盘

[目录](../../README.md) · [本章总览](00-overview.md) · [先修](02-mechanisms.md) · [下一篇](04-summary.md)

## 先理解：一套管理制度必须落实到人和动作

海港茶饮写了一条“不得承担过大风险”，并没有告诉员工什么交易可做、谁审批、超限怎样处理。有效制度需要目标、授权、指标、流程、监控与整改。金融机构资金规模更大、联系更密切，还要把单家机构的失误如何传染到整个体系考虑进去。

本课的制度控制采用机制级解释，不把任何一家机构的具体限额当作全行业通用数字。市场事实核验于2026-10-30，考试以适用指南为准。

## 考纲学习：把职责分开

交易或业务人员负责按授权经营并管理日常风险；独立风险与合规职能检查限额、方法和规则；内部审计评估控制是否有效；董事会和高级管理层承担相应治理责任。实际组织结构可不同，关键是不能由同一个人既开仓、修改记录、确认交易，又自行宣布一切正常。

独立例子：员工获准最多买USD20,000，私下买到200,000。如果后台只能看他自己交来的表，超限可能被隐藏。有效控制包括独立确认、对账、权限限制、异常报告和职责轮换。会计算对冲公式，不能替代执行这些流程。

## 香港制度中可以识别的风险工具

| 安排 | 要解决什么 | 不能推出什么 |
|---|---|---|
| 银行资本与审慎要求 | 吸收损失、限制过度风险 | 资本等于单独现金储备 |
| 流动性管理及压力测试 | 对付付款日不匹配与融资中断 | 总资产正就永远有现金 |
| 证券中介财务资源与客户资产控制 | 降低机构失稳、挪用与处理失误 | 持有证券必定不亏 |
| 保证金、净额、抵押品与违约管理 | 控制交易及结算敞口 | 清算所消灭全部风险 |
| 支付交收制度与DVP/PVP | 减少交收本金风险 | 发行人未来偿付被保证 |
| 监管协作、恢复及处置安排 | 降低机构失败的系统冲击 | 所有债权人必定全额获偿 |

监管思路可查[金管局银行监管文件库（含政策手册）](https://brdr.hkma.gov.hk/)及[银行审慎政策](https://www.hkma.gov.hk/eng/key-functions/banking/banking-legislation-policies-and-standards-implementation/)。本表是跨机制归纳，具体比例、适用范围和生效时间须对照相应文件。

## 宏观审慎：为什么每家都“看似合理”仍可能一起出事

假设很多银行都把抵押物业视为好资产，统一扩贷。房价上升时担保看起来更充足，信贷再增加；价格反转时大家同时收紧融资和卖出资产，价格进一步下跌。这是相互强化的反馈，不能只看每家银行单独的历史坏账率。

逆周期缓冲、集中度管理和压力测试等安排试图在好时期建立缓冲，减轻坏时期被迫集体去杠杆。它们不是保证永远没有衰退，也可能带来融资约束和政策取舍。判断政策时要说明目标、传导及代价。

## 危机案例一：亚洲金融危机的链条

教学归纳：外币债务、短期融资、资产泡沫和资本撤出可以互相强化。本币贬值提高外币负债的本币价值；短期资金不再续借造成现金缺口；被迫卖资产压低价格，银行和借款人资产负债表一起恶化。

独立数字例子：企业借USD1,000,000，本币每美元5元时负担5,000,000；若本币贬至每美元8元，美元本金不变，本币负担变8,000,000。增加60%，但不表示企业额外借了60%美元。若收入同样为美元，可有自然对冲；若收入仅本币，错配更明显。

香港1998年经历货币及金融市场压力，外汇基金在当时采取相关市场行动。重点学习多市场、利率与杠杆的联系，不把一次历史干预推断为将来所有股票损失都有政府承接。[金管局外汇基金历史与法定目标](https://www.hkma.gov.hk/eng/key-functions/reserves-management/exchange-funds-statutory-purposes-and-investment-objectives/)

## 危机案例二：全球金融危机的传染机制

教学归纳：低估信用风险、复杂证券化、杠杆、短期批发融资与机构联系，可使一部分贷款损失放大为融资和信心危机。将风险打包转移不代表风险已消失；需要看最后由谁持有、是否看懂、是否依赖同一融资来源。

独立例子：资产100，负债97，权益3。资产损失2看似仅2%，权益却从3降至1，损失2/3。若融资方要求更多抵押，机构可能在价格很差时出售，造成更大损失。这个简化模型解释杠杆放大，不代表所有历史机构都有相同数字。

启示：不能只看正常时期VaR；要看压力、流动性、对手方集中、抵押品相关性和资产透明度。复杂结构还会带来模型风险和信息不对称。

## 把复盘转化为可执行措施

| 失误 | 补救动作 | 怎么检查有效 |
|---|---|---|
| 单一客户占比过高 | 设集中度限额及例外批准 | 每日/定期看合并敞口 |
| 短钱长投 | 期限梯、现金缓冲、备用融资 | 压力下逐日现金缺口 |
| 隐藏交易 | 前后台分离和独立对账 | 未匹配项目及时升级 |
| 模型过信历史 | 多种压力情景、回溯检验 | 超阈值次数与原因分析 |
| 系统故障 | 业务连续性与灾难恢复 | 定期演练及修复记录 |

风险报告要使有权者采取行动。每天生成一百页表格却无人处理超限，不算完成监察。

## 自测与复述

案例：资产有正净值，但明天要补按金而借不到钱。主要是融资流动性问题；低价抛售可能再导致偿付能力恶化。措施不能只写“多分散”，还要增加可用现金、安排到期分布、检验融资可靠性。

复述：用“原始损失—杠杆—现金追缴—抛售—价格反馈”讲清一个危机场景，再写两项能中断链条的控制。完成[R16—R20](05-exercises.md)。
