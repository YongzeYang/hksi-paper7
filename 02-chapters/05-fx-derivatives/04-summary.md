# 第5章复习卡：先找敞口，再看合约

本章固定A/B=q表示1A=qB，汇率题先写完整等式。客户买基础货币用银行ask，卖基础货币用bid。

| 要点 | 快速回忆 | 回补 |
|---|---|---|
| 交叉汇率 | 展开成两笔兑换，让中间单位相消 | [5.1](01-core.md) |
| 远期升贴水 | (F−S)/S，再按题设期限年化 | [5.1](01-core.md) |
| 远期/期货 | 双方义务；期货有标准化、逐日结算等安排 | [5.2](02-mechanisms.md) |
| 买call/买put | 选择买/选择卖，付权利金 | [5.2](02-mechanisms.md) |
| 卖期权 | 收权利金，承担被行权时的相应义务 | [5.2](02-mechanisms.md) |
| 支付/利润 | 到期支付须再加减权利金等成本 | [计算专题](../../03-calculations/03-fx-derivatives.md) |
| 掉期 | 交换约定现金流；利率互换通常不交换同币名义本金 | [5.2](02-mechanisms.md) |
| 对冲/投机/套利 | 看原始业务和交易结构，不看工具名称 | [5.3](03-practice.md) |
| 香港交易/结算 | 产品走不同平台和结算路径 | [5.3](03-practice.md) |

四仓位到期净利润，忽略费用和权利金时间价值：买call=max(S−K,0)−c；卖call=c−max(S−K,0)；买put=max(K−S,0)−p；卖put=p−max(K−S,0)。按每单位算后再乘数量及合约乘数。

闭卷解释：进口商未来付美元，美元升值为何不利？买美元远期怎样降低预算波动？美元下跌时为何仍需履约？对冲有效时，为什么也可能要补保证金？
