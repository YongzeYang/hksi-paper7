# 4.1 债券到底承诺了什么

[目录](../../README.md) · [本章总览](00-overview.md) · [先修：时间价值](../../01-foundation/05-time-value.md) · [下一课](02-mechanisms.md)

## 先理解：把一张借条变成清晰的付款表

独立情境：海港茶饮已成长到适合相关融资的规模，发行一张面值1,000元、两年到期、年票息5%的普通固定息债券，按年末付息，到期一次还本。假设不违约、无提前终止或嵌入期权。

```text
发行时：投资者 ──认购款──> 公司
年1末：投资者 <──50元利息── 公司
年2末：投资者 <──50元利息+1,000元本金── 公司
```

债券 bond（債券）是债务证券，投资者持有合同债权。发行条款规定谁付款、支付什么币种、什么时候付款，以及担保、顺位等条件。公司普通股股息通常不承诺固定金额；普通债券则有合同付款义务，但**义务不等于付款一定实现**。

## 考纲学习：五个数字先分开

| 项目 | 意思 | 上例 |
|---|---|---|
| 面值face/par value | 条款中计息、偿还本金等使用的基准 | 1,000 |
| 票息率coupon rate | 年票息相对面值的比例 | 5% |
| 每期票息coupon | 每期合同利息金额 | 每年50 |
| 到期maturity | 规定还本等的日期 | 两年后 |
| 市场价格price | 今天交易愿付的金额 | 可低于、等于或高于1,000 |

买价950不会自动把每年票息变47.5；票息仍按面值和合同算。价格低于面值叫折价discount，高于叫溢价premium；这里“折价”描述价格与面值关系，和“折现现金流”这个计算过程应区分。

## 分类时问的是不同问题

| 分类轴 | 常见类别 | 主要差异 |
|---|---|---|
| 发行人 | 政府、公共机构、企业等 | 偿付来源与风险不同 |
| 计息 | 固定息、浮息、零息 | 现金流是否随参考利率重设 |
| 偿付顺位 | 优先、次级等 | 发生清算等情形的相对请求顺序 |
| 担保 | 有抵押/担保、无抵押 | 是否有特定支持及执行条件 |
| 期限 | 短期、长期、永续等 | 还本日期是否固定 |
| 选择权 | 可赎回、可回售、可转换等 | 谁可改变或选择部分现金流 |
| 币种 | 港元、美元、人民币等 | 外汇与资金来源匹配 |

同一债券可同时是“企业、美元、浮息、有担保”。这些不是互斥的同一层级标签。

固定息把票息写定，不把市场价格写定。浮息常按“参考利率+利差”定期重设，例如教学合同每年重设为参考率+1%。若参考率从3%到4%，下一适用期票息可能由4%到5%；尚须看重设日期、上下限和其他条款，不能假设立刻变化。

零息债没有中间票息，可能以折价发行；永续债没有普通固定到期还本日期，不能只看产品名便假设发行人一定在首个可赎回日赎回。可赎回callable是发行人的选择权，可回售puttable是持有人的相应选择权；可转换convertible把债权与转换股权选择相连，不能用无期权债券的简单关系解释全部价格行为。

## 为什么有人投资债券

债券可以提供约定现金流，帮助匹配未来支出；有些产品相对普通股在请求顺位上较前；市场也提供不同期限和信用水平。但必须连同风险讨论：发行人违约、利率变化、通胀侵蚀购买力、难以转售、外汇变化和再投资条件都可能影响结果。

“政府发行”不是对世界上所有政府、所有币种、所有日期的一张无风险保证。“保本”若写在合同里，也要问谁保证、什么条件、是否必须持有至指定日期以及保证人是否有履约能力。

## 利率有三组容易混淆的用法

1. **单利simple interest与复利compound interest**：前者只对原本金计息，后者把已计入利息继续滚存。
2. **名义年率与有效年率**：关注一年内计息频率；名义8%半年复利的有效年率=(1+0.08/2)²−1=8.16%。
3. **名义与实际real回报**：关注通胀；名义6%、通胀4%，实际购买力回报=1.06/1.04−1≈1.9231%。

第二组与第三组都可能出现“名义”，语境不同。不要只见中文两个字就代同一个公式。

## 完整例子：同一本金在不同约定下

本金10,000、年率10%、期限两年：单利利息2,000，到期12,000；按年复利到期12,100。多出的100来自第一年1,000利息在第二年再赚10%。若按半年名义10%复利，则四期每期5%，到期10,000×1.05⁴=12,155.06。三个数都可正确，但对应不同合同。

改变条件：利息每年取出不再投资，期末账户不会自行变成按原率复利的数额；要把取出的利息和本金分别看。

## 误区与自测

- “债券有固定息，所以价格固定。”错误：市场要求回报及信用条件会改变现值。
- “次级债也是债，所以清偿顺位和普通优先债相同。”错误：次级条款正是改变相对请求顺序。
- “零息就没有收益。”错误：买入价与约定兑付额的差异可形成收益，仍有风险。

自测：面值2,000、年票息4%、半年付息，每期多少？答：2,000×0.04/2=40。复述时同时说明这不是市场价格的4%。完成[D01—D06](05-exercises.md)。
