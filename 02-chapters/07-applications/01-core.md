# 7.1 企业融资：先看钱何时短缺，再挑工具

[目录](../../README.md) · [本章总览](00-overview.md) · [先修：现金流](../../01-foundation/02-company.md) · [下一课](02-mechanisms.md)

## 先理解：销售增长也可能需要更多资金

海港茶饮接到新订单，要先买原料、付工资，客户60天后才付款。利润率可能不错，但先支出后收款形成现金缺口。企业融资corporate finance（企業融資）处理企业投资、筹资及相关资金安排；专业顾问还可在上市、并购、重组等事项提供服务。

第一步不是问“哪种产品最流行”，而是确定资金用途、金额、时间、风险及企业能承受的义务。短期原料周转与长期建厂，可能需要不同安排。

## 考纲学习：先做资金计划

独立情境：公司现有可用现金100,000；未来三个月采购与工资支出合计300,000；预计收到客户款150,000。简化净缺口=300,000−100,000−150,000=50,000。

但总数相抵不保证每一天够钱。如果300,000全在月1支付、150,000在月3收到，月1最大缺口可能达到200,000。必须把现金按日期列开，才知道需要的最高临时融资及期限。

| 日期 | 收款 | 付款 | 累计现金（未新增融资） |
|---|---:|---:|---:|
| 期初 |  |  | 100,000 |
| 月1 | 0 | 300,000 | −200,000 |
| 月3 | 150,000 | 0 | −50,000 |

负数不是公司真的可无条件透支，而是未获资金支持时无法完成全部付款的信号。

## 债务、权益与内部资金的取舍

| 来源 | 优点的可能来源 | 代价与约束 |
|---|---|---|
| 保留盈利/内部现金 | 减少外部谈判和新增合同义务 | 有机会成本，金额可能不足 |
| 银行贷款 | 可按企业现金流和担保谈安排 | 利息、偿还、契诺和再融资风险 |
| 债券 | 接触更多资金提供者，期限可选择 | 发行及持续披露成本、市场窗口与信用要求 |
| 普通股 | 通常无固定还本日期，分享风险 | 所有权稀释、治理及要求回报 |

权益不是“免费钱”：股东承担剩余风险，通常要求相应回报。债务也不是因为“利息较低”便应无限增加；企业在差情境下仍可能要付息还本。融资决策必须与经营现金流相连。

长期设备若完全靠短期贷款反复续借，即使项目长期盈利，也可能在某次拒续时出问题。这叫再融资风险refinancing risk，与项目本身的利润风险不同但相互影响。

## 投资项目：把收益放回发生日期

扩展理解：净现值net present value，NPV，是未来净现金流现值减去初始投入。独立项目今天投100,000，一年后收60,000、两年后收60,000，适用折现率10%。

`NPV=60,000/1.1+60,000/1.1²−100,000=4,132.23`。

正值说明在该现金流与折现率假设下，超过要求回报后仍有剩余价值。不是保证赚4,132.23；若现金流估错，结果会变。将两年款项直接120,000减100,000得到20,000，没有处理时间价值。

改变条件：折现率20%时NPV=60,000/1.2+60,000/1.2²−100,000=−8,333.33。或者第二年收入下降也可能使项目不再满足要求。算式提供决策框架，不消除预测不确定性。

## 专业人员在发行、并购和重组中做什么

融资顾问分析资金需要、比较工具、评估结构与估值，并协调法律、会计、承销、投资者沟通等工作。上市还涉及适用的披露和审核；并购merger and acquisition（合併與收購，M&A）涉及目标估值、支付方式、尽职调查和整合风险；重组restructuring可能重新安排资产、债务或业务。

尽职调查due diligence（盡職審查）通过资料、验证及专业判断了解重要事实，不是“写一份报告后便没有遗漏风险”。估值也不是随意选择最高倍数；假设、可比性和现金流质量都要说明。

以股票支付收购价可减少即时现金支出，却可能稀释原股东；借钱收购可保持部分股权比例，却增加债务负担。协同效应synergy（協同效益）需要实现，不能在付款时就当成已收到的现金。

## 利益冲突

同一集团既建议企业融资，又向投资客户销售证券，可能面对收费或库存利益。适当的信息隔离、披露、独立判断及规则执行有助处理冲突，不能仅写“大家都专业”就认为问题不存在。具体法定义务按相应业务和适用规定核对。

## 自测与复述

若一个两个月后回款的订单只形成短期周转缺口，是否必定应发行长期普通股？答：不能一概而论，应比较金额、期限、费用、可获得性、现金流和风险。若是高不确定性长期扩张，过多短债可能不合适。
