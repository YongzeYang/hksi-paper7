# 第7章：金融业应用——三种工作怎样连接资金两端

[目录](../../README.md) · [先修：风险复习卡](../06-risk/04-summary.md) · [开始](01-core.md)

这一章将前六章放回具体工作：企业融资corporate finance、资产管理asset management、财务顾问financial advising。按[公开考纲](https://www.hksi.org/media/8440/p7-syllabus_eng_v35_clean.pdf)，重点是它们的意义、工作和相互依存。

| 顺序 | 核心问题 |
|---|---|
| [7.1 企业融资](01-core.md) | 公司需要多少钱、何时需要、怎样取得？ |
| [7.2 资产管理](02-mechanisms.md) | 投资者的钱怎样按目标配置、执行和复核？ |
| [7.3 财务顾问与协作](03-practice.md) | 怎样了解客户，并把产品与实际需要连接？ |
| [复习卡](04-summary.md) | 能否把一家公司融资和一个家庭投资连起来？ |
| [20题](05-exercises.md)及[解析](06-answers.md) | 能否判断角色、方案与风险？ |

学完应能说明：公司融资不等于所有者个人理财；基金资产不等于基金经理资产；客户愿意冒险不等于有能力承受；三种服务可以在同一机构出现，但职责与利益冲突仍须处理。

案例使用[统一设定](../../04-reference/01-case.md)，后续大额融资为公司成长后的独立情境。部分指标用作解释，不声称全部是考试要求。
