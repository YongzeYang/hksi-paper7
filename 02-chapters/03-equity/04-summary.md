# 第三章复习卡：一股股票的完整故事

[全书目录](../../README.md) · [本章总览](00-overview.md) · [下一篇：章节练习](05-exercises.md)

先修：完成本章三课。目标：用一页线索复述核心机制，找到仍需回补的部分。

## 先闭卷说出这条链

公司发行新股得到资金 → 投资者获得股东权利和剩余风险 → 公司经营改变未来现金流 → 投资者用盈利、账面资产或股息估值 → 二级市场买卖形成价格 → 交易后经清算交收完成资产转移。

## 必会公式与边界

| 项目 | 公式 | 先检查 |
|---|---|---|
| 持股比例 | 持有股数 ÷ 总股数 | 同一类权益及新旧股数口径 |
| 总回报率 | (期末价 − 期初价 + 股息) ÷ 期初价 | 持有期、税费和再投资假设 |
| 市盈率 P/E | 股价 ÷ 每股盈利 | 过去还是预测盈利、是否亏损 |
| 市账率 P/B | 股价 ÷ 每股账面净资产 | 资产账面值不等于可变现金额 |
| n 供一理论除权价 | (n × 旧价 + 认购价) ÷ (n + 1) | 认购新现金、比例及其他条件不变 |
| 一股旧股所附权利 | 旧价 − 理论除权价 | 不是整份新股认购资格价值 |
| 恒定增长股息模型 | 下一期股息 ÷ (要求回报率 − 增长率) | r > g、增长稳定、D1 不是 D0 |

## 易混概念

| 不要混淆 | 关键分界 |
|---|---|
| 普通股与债券 | 所有人剩余权益，对比合同债权 |
| 配售新股与配售旧股 | 公司收款，对比出售股东收款 |
| 供股与红股 | 股东另交认购款，对比通常无新现金流入 |
| 红股与拆股 | 储备资本化发股，对比改变股份单位 |
| 低股价与便宜 | 股价单位低，不等于估值低 |
| 股票指数与全部股票 | 指定成分及权重，不代表每只股票 |
| 成交与交收 | 达成买卖，对比实际转移证券及资金 |
| 政府企业私有化与上市公司私有化 | 政府持股转让，对比收购及撤销上市地位 |

## 六句必须能够解释的话

1. 普通股股东是剩余索偿人，因此可以分享增长，也可以损失全部已投资资本。
2. 二级市场转让股份通常不会把买家的钱交给发行公司。
3. 供股后要把新增资金与新总股数一起计算，不能只看股价下降。
4. 红股或拆股不能单靠增加股数创造企业价值。
5. 估值取决于现金流、增长和风险假设；任何单一倍数都不是买入保证。
6. 香港市场基础设施支持交易和交收，不能替代对投资风险的判断。
