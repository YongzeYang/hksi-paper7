## 三种版本不要混淆

| 对象 | 已核验情况 | 如何使用 |
|---|---|---|
| 公开 Syllabus 与 Expected Learning Outcomes | PDF 标明 2026-03-01 生效，文件名含 v35 | 确认章节范围与预期能力；文件名不代表已读到 3.5 版完整教材 |
| eStudy Guide 3.6 | 官方产品页明确 2026-07-06 至 2026-12-08 适用 | 在该时段考试者核对这一版及适用更新 |
| eStudy Guide 3.7 | 官方产品页明确 2026-12-09 起适用 | 此后考试者须再检查是否出现更新版或补充说明 |

直接依据：[公开考纲](https://www.hksi.org/media/8440/p7-syllabus_eng_v35_clean.pdf)、[3.6 版产品页](https://www.hksi.org/en/development/activities/1014955-le-paper-7-estudy-guide-version-36/)、[3.7 版产品页](https://www.hksi.org/en/development/activities/1015204-le-paper-7-estudy-guide-version-37/)。

官方更新汇总页的 3.6 结束日期曾显示不完整的 “December 2026”；本资料使用上述产品页给出的完整日期，没有把缺字自行补作证据。[官方更新入口](https://www.hksi.org/qualification/examinations/licensing-examination-for-securities-and-futures-intermediaries/updating-your-study-guides/)

## 这套资料已做与未做的校对

已做：读取公开考纲及学习成果，编写原创解释、例子与练习；为涉及香港制度的具体事实查阅官方公开页面；通过覆盖表记录教学位置。

未做：未取得官方学习指南 3.6、3.7 全文，未逐段比较两版修订，未确认教材内部所有术语措辞、数字、列表及复杂计算要求。公开考纲中的一个大标题，不能证明教材里全部细节已经覆盖。

HKSI 说明考试以相应现行指南及指定修订为依据；主要改动列表通常附在新指南末尾。实际市场新规也可能尚未纳入考试教材。因此碰到制度日期变化时，要分别写“现实规则的生效日期”和“该场考试采用的口径”，不能自动认为最新新闻就是考试答案。[官方教材更新规则](https://www.hksi.org/qualification/examinations/licensing-examination-for-securities-and-futures-intermediaries/updating-your-study-guides/)

## 考试日期确定后的核对清单

- [ ] 查官方更新页，记录考试日期对应的指南版本及补充公告。
- [ ] 在已报名者账户中取得相应指南；官方说明报名后可下载对应电子指南。
- [ ] 对照指南目录与章节学习成果，检查公开大纲之外的细目。
- [ ] 阅读指南末尾更新清单，逐项核对涉及市场制度、数字与机构称谓的内容。
- [ ] 特别检查认可机构制度改革、交易结算周期与安排、市场联通机制、产品范围、费用阈值及市场平台名称。
- [ ] 核对教材如何定义汇率报价、远期升贴水、日数惯例、久期及 VaR 等；保持题干条件优先。
- [ ] 核对官方计算器政策、考试语言、时长及当天安排。
- [ ] 将核对结果写入下表，并更新相关正文；无法确定的内容继续明确标注。

| 事项 | 目前状态 | 取得对应指南后要确认的内容 |
|---|---|---|
| 3.6 → 3.7 修订清单 | 未取得全文 | 逐项变动、适用时间、相关练习需否修改 |
| 指南内各产品的精确范围 | 公共考纲只能提供范围级信息 | 是否要求某个具体产品条款、名单或例外 |
| 计算深度与措辞 | 已教基本机制及选定扩展 | 哪些推导属于指南要求，哪些可只作理解 |
| 制度新旧口径 | 正文记录公开资料核验日期 | 对应考试是否已采用现实更新 |
| 官方样题时效 | 可用于观察题型 | 不由样题推断现行规则或真实考试权重 |

## 教学层次如何解读

“考纲学习”表示与公开范围和能力要求相连的教学内容；不是声称逐字复制或获得官方认可。“扩展理解”帮助解释机制，不承诺考试会考。未取得全文不妨碍先学习股债区别、现金流、复利等基础，但最终应将适用官方指南纳入备考核对。
