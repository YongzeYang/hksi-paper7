# 每日记录、间隔复习与错题本

[目录](../README.md) · [先修：学习路线](01-12-week-plan.md) · [下一步：掌握检查](03-mastery.md)

直接复制下面模板到本文件底部，或另建个人记录文件。公开仓库中如要记真实财务信息，请先自行判断哪些适合公开；学习示例使用虚构金额即可。

## 每日60分钟

| 阶段 | 时间 | 可观察的产出 |
|---|---:|---|
| 闭卷回顾 | 10分钟 | 从到期复习表选2—3项，不看正文复述 |
| 新知识 | 25分钟 | 读一段并画一张资金流/时间轴 |
| 练习 | 15分钟 | 先写推理再选答案，记录猜测 |
| 复述与记录 | 10分钟 | 用自己的话解释，并排下次复习 |

一课分多天时，在“停在哪里”写清下一小节标题。做不完不必加速跳过定义；把未完成项移到后续回补日。

### 每日模板

```text
学习日D__；日期____；实际用时____
今天读：文件/小节____
一个新概念：用白话说明____
谁给谁什么、何时给：____
完整数字例子：条件____；步骤____；单位____；结论____
改变一个条件会怎样：____
今天的题号/答案/信心：____
我仍不懂的问题：____
下次从这里继续：____
```

## 间隔复习：学习后第1、3、7、14天

对重要概念建立一行，复习用主动提取，不只重新看一遍。日期以实际首次学习日为起点；若某次复述失败，补学后重设短间隔。

| 概念/链接 | 首学日 | +1天 | +3天 | +7天 | +14天 | 能否换情境解释 |
|---|---|---|---|---|---|---|
| 例：票息率与YTM | D__ | D__ | D__ | D__ | D__ | 待检查 |
| 自填 |  |  |  |  |  |  |

每次复习三个动作：写定义；画现金流或举反例；做一道不同数字/不同主体的题。若待复习项太多，优先核心关系和近期错题，余下分散到周复习日。

## 错题记录：答对但靠猜也记

```text
题号及链接：____
我的答案____；正确答案____；信心（高/中/低）____
我原以为：____
实际关系是：____
触发错误的词：____（例如“每期”“名义”“卖出”“不正确”）
错误类型：概念/主体/时点/单位/公式条件/算术/读题
正确判断步骤：1.___ 2.___ 3.___
回补正文：____
自己改编一个例子：____
复测日期与结果：____
```

例如，把“利率升50bp”代成50，是单位错误。记录应写“50bp=0.50%=0.005，先换成小数再代久期”；只抄“答案−2%”无法防止下次再错。

## 每周复盘

- 我能闭卷解释的三件事：____。
- 仍要看答案才能完成的两件事：____。
- 一条跨章联系：____（例如折现同时解释股息模型与债券价格）。
- 下周先修是否够用：____。
- 已检查的来源版本与待核对条目：____。
